# Smart HUD -> APK (gratis, zonder compiler of EAS)

1. GitHub: nieuwe repo (Public) > "Add file > Upload files" > sleep ALLE bestanden uit deze map erin > Commit.
2. Repo > Settings > Pages > Source: "Deploy from a branch", Branch: main, / (root) > Save.
3. Na 1-2 min staat de app op https://JOUWNAAM.github.io/REPONAAM/ . Test dit eerst in Chrome op je telefoon.
4. Ga naar https://www.pwabuilder.com , plak die link, "Start" > "Package for stores" > Android > Generate.
   Package ID bv. com.smarthud.glasses. Download de zip en installeer de .apk (niet de .aab).
